# Challonge Notifier Bot

## Installation with [`uv`](https://github.com/astral-sh/uv)

0.  **Clone the repository:**

    ```bash
    git clone https://github.com/UmbrellaLeaf5/challonge_notifier_bot.git
    cd challonge_notifier_bot
    ```

1.  **Create venv and install dependencies:**

    ```bash
    uv sync
    ```

2.  **Activate the virtual environment:**
    - **Linux/macOS:**

      ```bash
      source .venv/bin/activate
      ```

    - **Windows (Git Bash/PowerShell):**

      ```bash
      .venv\Scripts\activate
      ```

3.  **One-liner:**

    ```bash
    uv sync && source .venv/Scripts/activate
    ```
